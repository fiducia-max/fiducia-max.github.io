# Fiducia Tax & Financial Solutions — website

Static website (GitHub Pages) with a Pages CMS admin.

- **Edit content:** https://app.pagescms.org → sign in with GitHub → open this repository.
- Content lives in `content/*.json`; uploaded images go to `media/`.
- Admin configuration: `.pages.yml`.
- After saving in the admin, the live site updates in about 1–2 minutes.
